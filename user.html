v1.4.0 (2026-08-08)
  • Redesigned the author profile as a compact data dossier with a unified KPI masthead.
  • Moved the activity chart higher, enlarged its plotting area, and consolidated profile insights into one signals rail.
v1.3.0 (2026-08-07)
  • Added 30-Sec Audio Preview Mini-Player with interactive track play buttons, iTunes search lookup, and animated wave equalizer.
  • Added high-resolution Story and Post creator cards with reliable avatar export.
  • Rebuilt the mobile author database and added a full-screen touch chart.
  • Fixed profile chart hover alignment and removed the duplicate desktop crosshair.
  • Removed profile comparison mode and its related controls.
v1.2.20 (2026-07-31)
  • Added Animate UI style GitHub Stars button badge in top header with live stargazers counter and spring animation.
v1.2.19 (2026-07-31)
  • Added optional 24h Growth histogram bars overlay on user activity chart and track history charts.
v1.2.18 (2026-07-31)
  • Fixed ReferenceError for svgElement in profile chart milestone calculations.
v1.2.17 (2026-07-31)
  • Fixed JS syntax error in profile activity chart script preventing page metrics load.
v1.2.16 (2026-07-31)
  • Added vertical date gridlines (weeks & 1st of month) and milestone/anniversary markers (⭐ views, 🎵 tracks, 🎂 anniversaries) on activity charts.
  • Fixed mobile track table overflow and layout cutoff on phone screens in creator profile.
v1.2.15 (2026-07-31)
  • Added multi-metric profile chart support (toggle Views, Tracks, or Dual series).
  • Dynamic track count history calculation based on earliest track appearance dates.

  • Made interactive lists and table rows keyboard-accessible for improved screen reader support.
v1.2.13 (2026-07-29)
